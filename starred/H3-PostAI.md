## 真实痛点

```
用户场景：
- 脑子里有干货，但写不出"让人转发的文案"
- 在Twitter/LinkedIn发了文章，阅读量只有几十
- 写一条帖子要1-2小时，改了无数遍还是不满意
- 同时运营多个平台，每个平台风格不同，时间不够用

现有解决方案的问题：
- Jasper.ai：$49/月，太贵了，个人创作者用不起
- Buffer：$6/月，但完全没有AI，只能排期
- Copy.ai：$49/月，定位企业，非个人创作者
- 国内的秘塔写作/秘蜂：面向中文，不适合Twitter英文语境

用户需求：
→ 输入我今天做了什么/产品/话题
→ 30秒后，5条高质量Twitter文案等着我
→ 一键复制，直接发
→ 不要注册，不要订阅，先让我用
```

## MVP设计

### 核心功能（3天完成）

```
1. 输入框
   - 输入今天做了什么/产品/话题（纯文字，100字以内）
   - 可选：目标平台（Twitter / LinkedIn / 两者都要）
   - 可选：语气（活泼 / 专业 / 幽默）

2. 输出
   - 5条Twitter文案（每条140字以内，带emoji建议）
   - 3条LinkedIn帖子（每条300字以内）
   - 1个 hashtags 建议

3. 交互
   - 一键复制（每条单独复制）
   - 预览模式（模拟Twitter/LinkedIn显示效果）
   - 再生按钮（不满意就换）
```

### 差异化设计

```
差异化1：极简输入
→ 不需要登录，不需要注册
→ 粘贴文字 → 点生成 → 复制走人
→ 全程不超过30秒

差异化2：按次付费（降低决策门槛）
→ 不卖订阅卖次数
→ $0.1/条（市场最低价）
→ 买10条$1，先试再买

差异化3：平台专属Prompt工程
→ Twitter：活泼、简短、带emoji、有钩子
→ LinkedIn：专业、有深度、带数据、有CTA
→ 不是通用AI，是专属文案机器
```

## 技术路径

```
前端：Next.js + TailwindCSS
     - 单页应用，不需要多路由
     - 移动端优先（创作者手机使用率高）

后端：Next.js API Routes
     - 调用GPT-4o生成文案
     - 简单的去重检测

AI：GPT-4o
     - 系统Prompt：Twitter/LinkedIn专属文案模板
     - 用户Prompt：直接生成

支付：Stripe
     - 按次购买（不强制订阅）
     - $1 = 10条，$5 = 60条，$10 = 150条

部署：Vercel（免费额度足够）

域名：postai.co / viralnow.ai / tweetcraft.io
```
