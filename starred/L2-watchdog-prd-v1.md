## 一、产品概述

### 1.1 产品一句话定位

> **帮出海独立开发者，盯着竞品的一举一动。**

### 1.2 产品slogan

> **"Know before they move."**

### 1.3 目标用户

| 用户类型 | 描述 |
|---------|------|
| 出海SaaS创始人 | 做AI工具/生产力软件出海 |
| 独立开发者 | ProductHunt发布产品，监控同类竞品 |
| 产品经理 | 负责竞品调研，需要数据支撑 |
| 投资人 | 监控被投企业的竞品动态 |

### 1.4 核心价值主张

| 痛点 | 解决方案 |
|------|---------|
| 不知道竞品什么时候变了 | AI自动监控，变化即告警 |
| 手动盯着太累，盯不过来 | 24/7自动监控，微信推送 |
| 变化发生后才知道，太被动 | 变化实时推送，第一时间响应 |
| 没有系统化竞品数据 | 变化历史存档，对比分析 |

## 二、账号体系

### 2.1 账号类型

| 账号类型 | 角色 | 说明 |
|---------|------|------|
| **管理员** | Admin | 全站管理，最高权限 |
| **普通用户** | User | 使用竞品监控功能 |

### 2.2 管理员账号

| 项目 | 内容 |
|------|------|
| **默认账号** | admin@126.com |
| **默认密码** | admin123 |
| **权限范围** | 全站管理：用户管理/竞品数据/告警配置/系统设置/日志审计 |
| **登录方式** | 邮箱+密码登录 |

### 2.3 普通用户登录方式

#### 国内用户
- **方式**：邮箱注册 + 邮箱登录
- 流程：输入邮箱 → 发送验证码 → 设置密码 → 注册成功
- 登录：邮箱 + 密码

#### 海外用户
- **方式**：Google一键注册登录
- 流程：点击Google图标 → 自动获取邮箱/昵称 → 注册成功
- 优势：3秒完成注册，无需记忆密码

## 三、界面设计规范

### 3.1 设计风格：AI科技简洁风

#### 配色方案

| 用途 | 色值 | 说明 |
|------|------|------|
| 主色 Primary | #4F46E5 | 科技蓝紫，AI感 |
| 辅助色 Secondary | #7C3AED | 渐变搭配 |
| 强调色 Accent | #06B6D4 | 青色，链接/高亮 |
| 背景色 Background | #0F172A | 深色背景，AI感 |
| 卡片背景 | #1E293B | 深灰蓝，卡片/输入框 |
| 文字主色 | #F8FAFC | 白色文字 |
| 文字次色 | #94A3B8 | 灰色文字 |
| 成功色 | #10B981 | 绿色，变化减少 |
| 警告色 | #F59E0B | 橙色，新功能 |

| 告警色 Alert | #F97316 | 橙色，重要变化 |

| 用途 | 字体 | 大小 | 字重 |
|------|------|------|------|
| 主标题 H1 | Inter | 28px | 700 |
| 页面标题 H2 | Inter | 22px | 600 |
| 卡片标题 H3 | Inter | 16px | 600 |
| 正文 Body | Inter | 14px | 400 |
| 辅助文字 | Inter | 12px | 400 |
| 按钮文字 | Inter | 14px | 500 |

#### 圆角与间距

| 项目 | 规范 |
|------|------|
| 卡片圆角 | 12px |
| 按钮圆角 | 8px |
| 输入框圆角 | 8px |
| 页面内边距 | 24px |
| 卡片间距 | 16px |
| 元素间距 | 8px |

#### AI科技元素

| 元素 | 样式 |
|------|------|
| 背景 | 深色渐变 + 网格线 + 粒子效果（可选） |
| 按钮 | 渐变边框 + 微发光效果 |
| 卡片 | 边框使用1px半透明渐变 |
| 图标 | Lucide Icons，线条风格 |
| 告警卡片 | 左边框颜色标识变化类型 |
| Loading | 脉冲动画 + "监控中..."文案 |
| 空状态 | AI监控机器人插画 |

### 5.2 数据库设计

#### 用户表（users）

```sql
CREATE TABLE users (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  email VARCHAR(255) UNIQUE,
  password_hash VARCHAR(255),
  full_name VARCHAR(255),
  avatar_url TEXT,
  auth_provider VARCHAR(50), -- 'email' | 'google'
  role VARCHAR(50) DEFAULT 'user', -- 'admin' | 'user'
  plan VARCHAR(50) DEFAULT 'free', -- 'free' | 'starter' | 'growth' | 'agency'
  wechat_openid VARCHAR(255),
  wechat_token VARCHAR(255),
  slack_webhook VARCHAR(500),
  discord_webhook VARCHAR(500),
  alert_frequency VARCHAR(50) DEFAULT 'daily',
  alert_types TEXT[], -- ['price', 'feature', 'copy', 'redesign', 'app_update']
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);
```

#### 竞品表（competitors）

```sql
CREATE TABLE competitors (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES users(id),
  name VARCHAR(255),
  url TEXT,
  type VARCHAR(50), -- 'saas' | 'app_store' | 'ecommerce'
  status VARCHAR(50) DEFAULT 'active', -- 'active' | 'paused' | 'error'
  last_checked_at TIMESTAMP,
  last_changed_at TIMESTAMP,
  change_count INTEGER DEFAULT 0,
  alert_enabled BOOLEAN DEFAULT true,
  alert_frequency VARCHAR(50) DEFAULT 'daily',
  created_at TIMESTAMP DEFAULT NOW()
);
```

#### 变化记录表（changes）

```sql
CREATE TABLE changes (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  competitor_id UUID REFERENCES competitors(id),
  user_id UUID REFERENCES users(id),
  change_type VARCHAR(50), -- 'price' | 'feature' | 'copy' | 'redesign' | 'app_update'
  change_summary TEXT,
  before_content TEXT,
  after_content TEXT,
  before_screenshot_url TEXT,
  after_screenshot_url TEXT,
  alert_sent BOOLEAN DEFAULT false,
  created_at TIMESTAMP DEFAULT NOW()
);
```

#### 快照表（snapshots）

```sql
CREATE TABLE snapshots (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  competitor_id UUID REFERENCES competitors(id),
  user_id UUID REFERENCES users(id),
  page_content TEXT,
  screenshot_url TEXT,
  price_value VARCHAR(100),
  features TEXT[],
  created_at TIMESTAMP DEFAULT NOW()
);
```

## 七、非功能需求

### 7.1 性能要求

| 指标 | 要求 |
|------|------|
| 页面加载时间 | < 2秒 |
| API响应时间 | < 1秒 |
| 竞品扫描时间 | < 30秒/个 |
| 告警推送延迟 | < 5分钟 |

### 7.2 安全要求

- 所有数据传输使用HTTPS
- 密码使用bcrypt加密存储
- Webhook URL加密存储
- 敏感操作记录审计日志
- 防止SQL注入和XSS攻击
- 抓取遵守robots.txt

### 7.3 合规要求

- 符合GDPR（欧盟用户数据保护）
- 抓取行为遵守目标网站ToS
- 不存储竞品敏感商业数据
