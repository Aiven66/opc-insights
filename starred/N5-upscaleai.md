## 真实痛点

```
用户场景：
- 微信截图太小，放大就糊
- 旧照片模糊，想修复高清
- 电商卖家产品图不够大
- 设计师需要高清素材
- 社交媒体需要高清图片

现有解决方案的问题：
- Photoshop：太专业，学习成本高
- Upscayl：需下载软件
- Let's Enhance：$12/月
- 在线工具：都有水印/注册限制

用户需求：
→ 上传小图
→ 自动放大4x或8x
→ 下载高清不失真
→ 1分钟内完成
```

## MVP设计

### 核心功能

```
1. 图片上传
   支持：JPG / PNG / WEBP
   最大：10MB / 4000×4000px

2. AI放大
   选择倍数：2x / 4x / 8x
   自动处理：
   - 超分辨率放大
   - 去噪
   - 细节增强

3. 预览 + 下载
   - 前后对比滑块
   - 一键下载PNG
```

### 附加功能（v2）

```
- 颜色增强
- 人脸增强（专用于人像）
- 动漫/插画专用模式
```

## 技术路径

```
前端：Next.js + TailwindCSS
后端：Next.js API Routes
图片处理：
  选项A：Replicate API（Real-ESRGAN/SwinSR）
  选项B：Stripe + Supabase存储
  选项C：Cloudflare AI Workers
部署：Vercel
支付：Stripe
域名：upscaleai.co / pixelboost.ai
```
