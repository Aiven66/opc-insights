# AICompare — 国产AI工具对比站

---

## 一、产品概述

### 1.1 产品定位

```
AICompare = 国产AI工具的第三方评测平台

AICompare 是一家专注于国产AI工具的第三方评测平台。
豆包 vs 文心 vs 通义 vs Kimi，谁更强？我们用真实数据说话。
每周更新客观对比报告，帮用户选对AI工具。
```

### 1.2 Slogan

```
国产AI哪家强？数据告诉你。
```

### 1.3 核心价值

| 价值点 | 说明 |
|--------|------|
| **客观真实** | 不是软广，是真实数据对比 |
| **场景化评测** | 不是跑分，是实际使用场景对比 |
| **持续更新** | 每周更新，紧跟版本迭代 |
| **用户评分** | 真实用户的评分和反馈 |

---

## 二、为什么做这个产品？

### 2.1 市场背景

| 信号 | 说明 |
|------|------|
| B站"国产AI对比"内容持续热门 | 用户想知道哪个AI更强 |
| 小红书大量"AI工具求推荐"帖子 | 需求真实存在 |
| 各家AI都说自己最强 | 没有客观第三方 |
| AI工具迭代快（周更/月更） | 需要持续更新的评测 |

### 2.2 用户痛点

```
痛点1：不知道选哪个AI
→ 豆包说"最懂中文"，文心说"中文最强"，通义说"最全能"
→ 到底信谁？

痛点2：看了评测还是不知道怎么选
→ 现有评测都是软广，没有客观数据
→ 看了等于没看

痛点3：AI更新太快，评测过时
→ 上个月的评测，这个月就不准了
→ 需要持续跟踪
```

## 四、竞品分析

### 4.1 直接竞品

| 竞品 | 定位 | 劣势 |
|------|------|------|
| 各AI官网 | 自己说自己好 | 不客观 |
| 科技媒体 | 偶尔做对比 | 不持续、软广多 |
| B站up主 | 视频对比 | 太主观、时效性差 |
| 小红书笔记 | 用户分享 | 样本太小、不系统 |

### 4.2 竞品空白

```
✅ 没有专注国产AI的第三方评测平台
✅ 没有自动化测试 + 主观评测结合
✅ 没有持续更新的对比机制
✅ 没有用户真实评分系统
```

## 五、产品功能设计

### 5.1 MVP功能矩阵

| 功能 | 说明 | 优先级 |
|------|------|--------|
| **AI能力对比** | 同一问题，4个AI同时回答，对比效果 | P0 |
| **场景化评测** | 不同场景（写作/编程/翻译）专项对比 | P0 |
| **用户评分系统** | 真实用户评分和反馈 | P0 |
| **周更报告** | 每周更新对比数据 | P0 |
| **工具推荐** | 基于测试结果，推荐最适合的工具 | P1 |
| **订阅通知** | 工具更新时通知用户 | P2 |

### 5.2 P0核心功能详解

---

#### 🔵 功能1：AI能力对比

**输入**：用户选择一个场景 + 输入具体问题

**支持的AI**：

| AI工具 | 所属公司 | 支持情况 |
|--------|---------|---------|
| 豆包 | 字节跳动 | ✅ 完全支持 |
| 文心一言 | 百度 | ✅ 完全支持 |
| 通义千问 | 阿里云 | ✅ 完全支持 |
| Kimi | 月之暗面 | ✅ 完全支持 |

**支持的场景**：

| 场景 | 示例问题 |
|------|---------|
| 写作助手 | 写一封商务邮件 |
| 编程辅助 | 写一个Python爬虫 |
| 翻译 | 中译英一段话 |
| 知识问答 | 解释量子计算 |
| 内容创作 | 写小红书风格的推文 |
| 数据分析 | 分析这份CSV数据 |

**输出**：

```
【问题】：写一封商务邮件，邀请客户参加产品发布会

【豆包回答】
[回答内容]
评分：★★★☆☆

【文心一言回答】
[回答内容]
评分：★★★★☆

【通义千问回答】
[回答内容]
评分：★★★★☆

【Kimi回答】
[回答内容]
评分：★★★☆☆

【综合推荐】
最适合这个场景：文心一言
原因：格式规范，语气专业
```

---

#### 🔵 功能2：场景化评测

**评测维度**：

| 维度 | 说明 |
|------|------|
| 回答质量 | 回答是否准确、有用 |
| 响应速度 | 回复时间快慢 |
| 中文理解 | 对中文的理解程度 |
| 专业术语 | 对行业术语的处理 |
| 创意能力 | 回答的创意和独特性 |

**评测报告模板**：

```
【场景】：内容创作

【维度对比】
| AI工具 | 回答质量 | 响应速度 | 中文理解 | 专业术语 | 创意能力 | 综合 |
|--------|---------|---------|---------|---------|---------|------|
| 豆包    | ★★★★☆   | ★★★★★   | ★★★★★   | ★★★☆☆   | ★★★★☆   | 4.2 |
| 文心一言 | ★★★★★   | ★★★★☆   | ★★★★★   | ★★★★★   | ★★★☆☆   | 4.4 |
| 通义千问 | ★★★★☆   | ★★★★☆   | ★★★★☆   | ★★★★☆   | ★★★★☆   | 4.1 |
| Kimi    | ★★★★☆   | ★★★★★   | ★★★★☆   | ★★★☆☆   | ★★★★★   | 4.2 |

【结论】
- 商务写作首选：文心一言
- 创意内容首选：Kimi
- 日常问答首选：豆包
- 综合能力首选：通义千问
```

---

#### 🔵 功能3：用户评分系统

**评分机制**：

| 评分项 | 说明 |
|--------|------|
| 回答质量 | 1-5星 |
| 响应速度 | 1-5星 |
| 性价比 | 1-5星 |
| 易用性 | 1-5星 |
| 综合评分 | 自动计算 |

**用户反馈**：

```
【用户评价示例】
@小明
评分：★★★★☆
使用场景：写代码
评价：Kimi写代码确实强，但有时候会过度发挥

@小红
评分：★★★☆☆
使用场景：写文案
评价：豆包最适合中国宝宝体质，但创意一般
```

#### 🔵 功能4：周更报告

**更新内容**：

| 更新项 | 频率 | 说明 |
|--------|------|------|
| 能力对比数据 | 每周 | 更新各AI的最新表现 |

## 六、商业模式

### 6.1 收入来源

| 收入来源 | 说明 | 占比目标 |
|---------|------|---------|
| **付费报告订阅** | 深度对比报告 + 数据分析 | 60% |
| **企业服务** | 企业AI选型咨询 + 定制报告 | 25% |

| **Team** | $49/月 | 5账号 + 企业定制报告 |
