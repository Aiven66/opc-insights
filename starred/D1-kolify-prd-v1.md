## 一、产品概述

### 1.1 产品一句话定位

> **用自然语言描述你的目标KOL，AI自动找到最匹配的KOL，生成个性化邮件并自动发送——全链路AI驱动，让KOL外联从手工变成自动化。**

### 1.2 产品slogan

> **"Tell us who you want. We'll find them. We'll reach them."**

### 1.3 目标用户

| 用户类型 | 描述 |
|---------|------|
| TikTok Shop卖家 | 美妆/服装/3C等出海品牌，找KOL带货 |
| 出海DTC品牌 | 想做KOL营销但预算有限的独立站 |
| 独立站创业者 | 想通过KOL推广引流到独立站 |
| Instagram商家 | 想找Instagram KOL合作的小B商家 |

### 1.4 核心价值主张

| 痛点 | 解决方案 |
|------|---------|
| 找不到对的KOL | AI自然语言发现，匹配度评分 |
| 不知道商务邮箱 | Apollo.io/Hunter.io自动挖掘 |
| 邮件像群发，回复率低 | AI分析KOL内容，生成个性化邮件 |
| 发完没有跟进 | AI自动追踪+二次跟进 |
| 竞品太贵用不起 | $49/月起，只有Grin的1/20 |

### 2.3 普通用户登录方式

#### 国内用户
- **方式**：邮箱注册 + 邮箱登录

- **方式**：Google一键注册登录
- 流程：点击Google图标 → 自动获取邮箱/昵称 → 注册成功
- 优势：3秒完成注册，无需记忆密码

### 5.2 数据库设计

#### 用户表（users）

```sql
CREATE TABLE users (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  email VARCHAR(255) UNIQUE,
  password_hash VARCHAR(255),
  full_name VARCHAR(255),
  avatar_url TEXT,
  auth_provider VARCHAR(50), -- 'email' | 'google'
  role VARCHAR(50) DEFAULT 'user', -- 'admin' | 'user'
  plan VARCHAR(50) DEFAULT 'free', -- 'free' | 'starter' | 'growth' | 'agency'
  gmail_token TEXT, -- Gmail API refresh token
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);
```

#### 品牌表（brands）

```sql
CREATE TABLE brands (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES users(id),
  name VARCHAR(255),
  description TEXT,
  product_description TEXT,
  cooperation_policy TEXT,
  logo_url TEXT,
  created_at TIMESTAMP DEFAULT NOW()
);
```

#### KOL表（kol_list）

```sql
CREATE TABLE kol_list (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES users(id),
  platform VARCHAR(50), -- 'tiktok' | 'instagram' | 'youtube'
  handle VARCHAR(255),
  display_name VARCHAR(255),
  profile_url TEXT,
  followers_count INTEGER,
  avg_views INTEGER,
  engagement_rate DECIMAL(5,2),
  country VARCHAR(100),
  category VARCHAR(100),
  content_style TEXT,
  email VARCHAR(255),
  match_score INTEGER,
  is_willing_coop BOOLEAN DEFAULT false,
  notes TEXT,
  created_at TIMESTAMP DEFAULT NOW()
);
```

#### 外联记录表（outreach）

```sql
CREATE TABLE outreach (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES users(id),
  kol_id UUID REFERENCES kol_list(id),
  brand_id UUID REFERENCES brands(id),
  email_variant VARCHAR(50), -- 'enthusiastic' | 'praise' | 'value'
  email_subject TEXT,
  email_body TEXT,
  status VARCHAR(50) DEFAULT 'pending', -- 'pending' | 'sent' | 'opened' | 'replied' | 'cooped'
  sent_at TIMESTAMP,
  opened_at TIMESTAMP,
  replied_at TIMESTAMP,
  followup_count INTEGER DEFAULT 0,
  created_at TIMESTAMP DEFAULT NOW()
);
```
