## 📋 功能清单

### 功能1: 项目诊断
**输入：** 创始人基本信息（3句话）+ 阶段 + 融资需求

**输出：**
- 融资阶段判断（种子/天使/A轮）
- 目标投资人类型（战略/财务/政府）
- 估值建议区间
- 核心卖点提炼

**示例输出：**
```
📊 项目诊断报告

阶段判断：Pre-A轮（天使轮）
目标类型：天使投资 + 产业资本
估值区间：1500-2500万（取决于收入）
核心卖点：
  1. AI驱动，效率提升3倍
  2. 垂直切入，早期占位
  3. 团队背景强（BAT背景）
建议：先拿100-200万，稀释10-15%
```

---

### 功能2: 投资人画像匹配
**输入：** 项目信息 + 融资需求

**输出：**
- Top 20 匹配投资人名单
- 每个投资人的关注点
- 近期出手案例
- 联系方式/LinkedIn

**匹配维度：**
- 行业偏好（AI/消费/硬科技/医疗...）
- 阶段偏好（早期/成长期/后期）
- 金额偏好（小/中/大）
- 地域偏好（北京/上海/深圳/海外）

---

### 功能3: Cold Email生成
**输入：** 创始人信息 + 项目介绍 + 目标投资人

**输出：**
- 定制化Email模板（针对每个投资人）
- 邮件主题优化（A/B测试版本）
- 最佳发送时间建议
- 跟进节奏建议

**示例：**
```
邮件主题：[融资] AI驱动的新一代XX，创始团队来自XX，已完成MVP验证

正文：
Hi [投资人名字]，

我是[创始人]，正在做[项目名称]——
[一句话概括做什么]。

目前已完成[关键里程碑]，核心数据：
- [数据1]
- [数据2]

了解到您近期投资了[相关项目]，相信在[共同点]上我们有合作空间。

如果您感兴趣，我很乐意做一个15分钟的简短介绍。

期待您的回复！

[创始人]
[联系方式]
```

---

### 功能4: 约谈模拟
**输入：** 创始人选择模拟类型

**可选角色：**
- 模拟天使投资人
- 模拟VC合伙人
- 模拟产业资本

**AI模拟内容：**
- 问真实的投资人问题
- 指出回答的问题
- 给出优化建议

## ⚠️ 风险与挑战

### 风险1: 鸡生蛋问题
**问题：** 没有投资人，就没有数据；没有数据，匹配就不准

**解决方案：**
- 先做内容吸引创始人
- 用创始人社区换投资人入驻
- 早期靠人工+AI混合

### 风险2: 信任问题
**问题：** 创始人敢不敢把核心信息给一个AI？

**解决方案：**
- 数据隐私承诺
- 不要求敏感信息
- 用公开数据为主

### 风险3: 竞争壁垒
**问题：** 这个看起来谁都能做

**解决方案：**
- 垂直深耕（只做AI赛道？只做出海项目？）
- 积累独家投资人关系
- 做出成功案例

### 风险4: 执行能力
**问题：** 你是一个产品经理 + 内容创作者，没有投资人资源

**解决方案：**
- 先用内容杠杆验证需求
- 找1-2个懂融资的合伙人
- 用OpenClaw杠杆解决技术问题

## 🗺️ 发展路径

### Phase 1: 内容验证（1-2个月）
- 用公众号测试需求
- 收集创始人痛点
- 验证付费意愿
- 产出：10篇相关文章 + 100+潜在用户

### Phase 2: MVP开发（1个月）
- 用OpenClaw搭建Agent
- 抓取公开投资人数据
- 实现核心匹配功能
- 产出：可用的MVP

### Phase 3: 小范围测试（1个月）
- 找10个创始人试用
- 收集反馈迭代
- 打磨变现模型
- 产出：10个付费用户 + 案例

### Phase 4: 规模化（持续）
- 启动付费
- 积累案例
- 引入合伙人
- 产出：100+付费用户 + 稳定收入
