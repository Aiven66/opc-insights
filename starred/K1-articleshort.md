### 核心API流程

```typescript
// 用户操作流程
async function handleArticleToShort(url: string, platform: string, duration: number) {
  // 1. 解析微信公众号文章
  const article = await parseWeChatArticle(url)

  // 2. 用AI生成短视频脚本
  const script = await gpt4o.generateScript({
    article,
    platform,      // '抖音' | 'B站' | '小红书'
    duration,      // 60 | 120 | 180 秒
    style: '爆款'  // 爆款风格
  })

  // 3. 用TTS生成配音
  const audio = await tts.generateAudio(script.text)

  // 4. 返回结果
  return { script, audio }
}
```

## 为什么不选竞品

**剪映**：做的是剪辑工具，用户需要自己写脚本。ArticleShort 帮你写脚本。

**秘塔**：做的是文字改写工具，不懂抖音/小红书算法。ArticleShort 生成的脚本是专门针对平台算法优化的。

**即创**：抖音官方的AI创作工具，但只支持抖音内容。ArticleShort 专门服务微信公众号创作者。

**轻抖**：只能提取文案，不能生成脚本。ArticleShort 是完整的工作流。
