## 一句话定位

---

## 背景与痛点

**用户故事**：

小李，27岁，程序员，去年开始做独立开发者：
- 在 Gumroad / LemonSqueezy / Stripe 上收款，收的都是美元
- 用 Claude Code 开发产品，月支出 $200 在各种 AI API 上
- 没有会计，年底不知道怎么报税
- 每次给客户开发票要手动填表格，头疼

**核心痛点**：
1. 多平台收款（Stripe/PayPal/Gumroad/LemonSqueezy）账单分散，汇总麻烦
2. 支出分类靠手记，不知道哪些可以抵税
3. Invoice/Receipt 要手动做，不规范
4. 跨境收入税务规则复杂（美国/EU/东南亚规则不同）

---

## MVP功能清单

### P0（核心闭环）

| # | 功能 | 描述 |
|---|------|------|
| F1 | **Stripe账单同步** | 一键连接Stripe账户，自动拉取所有收入记录 |
| F2 | **AI支出分类** | 读取银行/支付账单，AI自动识别收入/支出，可抵扣标注 |
| F3 | **Invoice自动生成** | 输入客户信息，AI生成专业Invoice（PDF格式） |
| F4 | **月报生成** | 每月自动生成收支报告：收入/支出/净利润/预估税 |

### P1（运营闭环）

| # | 功能 | 描述 |
|---|------|------|
| F5 | **Receipt归档** | 自动存储所有收据，支持关键词搜索 |
| F6 | **多平台支持** | 支持 PayPal / Gumroad / LemonSqueezy / LemonSqueezy / 银行API |
| F7 | **税务估算** | 根据收入所在国家，估算应缴税额（美国/EU/东南亚） |
| F8 | **Accountant导出** | 一键导出 PDF/CSV，给会计或报税季用 |

### P2（增长功能）

| # | 功能 | 描述 |
|---|------|------|
| F9 | **多货币换算** | 自动按实时汇率换算，显示人民币/美元收益 |
| F10 | **支出提醒** | 超过预算时提醒（API支出异常检测） |
| F11 | **年度税务报告** | 年底自动生成完整税务数据包 |
| F12 | **团队版** | 支持多人/多公司管理 |

## 技术方案

### 数据源集成

| 平台 | API | 数据 |
|------|-----|------|
| Stripe | `api.stripe.com` | 收入、退款、支出、订阅 |
| PayPal | PayPal API | 收款、余额、交易 |
| LemonSqueezy | LemonSqueezy API | 订阅收入、退款 |
| Gumroad | Gumroad API | 销售记录 |
| 银行 | Plaid / Wise API | 支出记录 |

### AI功能

```
账单数据 → Claude解析 → 支出分类（餐饮/软件/硬件/广告等）
                    → 识别可抵扣项目（AI API费用/工具订阅等）
                    → 生成月度报告
                    → 生成Invoice
```

### 技术栈建议

```
前端: Next.js + TailwindCSS + shadcn/ui
后端: Next.js API Routes
数据库: Supabase (PostgreSQL)
AI: Claude API (支出分类/Invoice生成)
支付: Stripe Connect (平台收款)
部署: Vercel
```

## 关键风险

| 风险 | 等级 | 应对 |
|------|------|------|
| 税务规则复杂，不同国家差异大 | 🟡 中 | MVP只做美国/EU主要规则，明确免责声明 |
