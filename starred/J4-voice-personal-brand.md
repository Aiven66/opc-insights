## 一句话定位

> 把你的公众号文章，一键变成你自己的声音播客。

---

## 核心差异化（用户亲口说的需求）

**普通版**：上传文本 → AI生成音频

**这个产品的特别之处**：
1. **输入源**：微信文章链接 / 任意URL / 本地上传文本/PDF/Word
2. **输出**：播客音频（你克隆的声音）
3. **用户自己就是素材源**：公众号文章直接转，不用重新写

---

## 背景与痛点

**用户故事**：

小北，AI科技博主，写了2年公众号：
- 写了100多篇深度文章，文字积累很深
- 想做播客/音频内容扩大影响力，但没时间重新录音
- 用过TTS工具，但机器声音太假，听众反馈很差
- 想克隆自己的声音，但技术门槛高，不知道怎么搞

**核心痛点**：
1. 公众号内容写完了，想复用做播客，但要从零录音
2. 现有TTS工具声音太假，听众能听出来
3. 克隆声音技术门槛高（ElevenLabs $30/月起步）
4. 没有简单的一键工具：文章链接 → 克隆声音播客

## MVP功能清单

### P0（核心闭环）

| # | 功能 | 描述 |

| F8 | **语速/语调调节** | 调整克隆声音的语速和语调 |
| F9 | **分段生成** | 长文自动分段，每段独立音频 |

|---|------|------|

## 技术方案

### 核心技术

| 技术 | 用途 |
|------|------|
| 微信文章解析 | 将公众号链接转为纯文本 |
| Claude API | 文本口语化优化 |
| ElevenLabs API | 声音克隆 + TTS |
| 或者 Coqui/T蝝 S | 开源克隆方案，降低成本 |
| RSS生成器 | 播客订阅 |

### AI功能

```
微信链接 → 文章解析（提取标题+正文）
         → 文本口语化（书面语→更适合听的语气）
         → 用户克隆声音TTS
         → 添加背景BGM（可选）
         → 导出MP3 + 生成RSS
```

### 技术栈

```
前端: Next.js + TailwindCSS + shadcn/ui
后端: Next.js API Routes
AI: Claude API (口语化) + ElevenLabs API (克隆+TTS)
播客: RSS生成
部署: Vercel
存储: Cloudflare R2 (音频文件)
```

## 关键风险

| 风险 | 等级 | 应对 |
|------|------|------|
| 微信文章解析可能被封 | 🟡 中 | 用第三方服务；或者让用户手动复制文本 |
| 声音克隆成本（ElevenLabs $30/月起） | 🟡 中 | 先用开源方案（Coqui）；或者按生成量收费 |
| 用户对克隆声音接受度不确定 | 🟡 中 | 先做真实声音版本，克隆作为高级功能 |
| 播客分发门槛高（小宇宙需审核） | 🟢 低 | 先做MP3下载，RSS分发是加分功能 |
