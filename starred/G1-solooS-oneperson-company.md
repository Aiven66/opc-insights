## 一、产品概述

### 1.1 一句话定位

帮助普通人用AI从零建立一人公司，提供方向诊断→工具包推荐→7个月执行路线图的一站式操作系统。

### 1.2 Slogan

**"一人公司，从这本通开始"**

### 1.3 解决的问题

```
传统路径的问题：
学AI → 做产品 → 找用户 → 变现
90%的人卡在"找用户"这一步，血本无归

SoloOS的路径：
先诊断最适合你的方向 → 再给工具包 → 最后给执行路线图
让你从第一天就知道往哪走，每一步都有反馈
```

### 1.4 目标用户

```
🎯 想做独立开发者但不知道从哪开始的人
🎯 已经做产品但变现困难的开发者
🎯 想用AI杠杆放大个人能力的职场人
🎯 想从0到1建立个人商业闭环的创业者
```

### 1.5 市场机会

```
数据信号：
- Twitter: "普通人用AI月入7万" 方法论爆款（2026-05-10）
- GitHub: hello-agents 45,917★（从零构建AI智能体教程爆火）
- GitHub: dive-into-llms 36,627★（动手学大模型教程同样热门）

- AI HOT: Redis创始人用C语言引擎将大模型装进个人电脑

市场判断：

→ 现在入场 = 在洗牌前建立用户基础
```

## 二、核心功能矩阵

### 2.1 产品功能矩阵（三大核心模块）

| 功能模块 | 说明 | 优先级 |
|---------|------|--------|
| **方向诊断** | AI诊断最适合你的一人公司方向 | P0 核心 |
| **工具包推荐** | 根据方向推荐AI工具组合（买什么/免费什么） | P0 核心 |
| **执行路线图** | 7个月按周执行清单 + 里程碑检查 | P1 核心 |
| **社群答疑** | 每周答疑 + 成功案例分享 | P2 增强 |

### 2.2 MVP阶段核心功能（3步极简）

```
【第一步：一人公司诊断】（免费引流）
输入：你的技能 + 兴趣 + 可用时间
处理：AI分析8个已验证方向 + 你的匹配度
输出：最适合你的1-2个方向 + 理由

【第二步：AI工具包推荐】（免费引流）
输入：你选择的方向
处理：匹配该方向的工具组合
输出：3-5个AI工具（免费/付费/性价比推荐）

【第三步：7个月执行路线图】（付费核心产品）
输入：你的方向 + 起点
处理：生成按周执行清单
输出：
- 每周任务清单（本周做什么/下周做什么）
- 变现节点（第1/3/6个月的收入目标）
- 里程碑检查（1个月/3个月/6个月验收标准）
```

### 2.3 增强功能（v1.1）

```
【工具包代购】
- 用户选择工具后，一键生成购买链接
- Affiliate佣金自动追踪
- 节省用户时间 = 增加转化

【成功案例库】
- 整理20个一人公司真实案例
- 案例包含：方向 + 工具 + 月收入 + 踩坑 + 经验
- 付费用户可见

【定时提醒】
- 微信每周一推送本周任务
- 微信每月提醒里程碑检查
- 提高执行完成率
```

### 2.4 不做的功能（MVP阶段）

| 不做 | 原因 |
|------|------|
| ❌ AI自动执行 | MVP只给路线图，执行靠用户自己 |
| ❌ 多方向同时推进 | 专注一个方向，做透再扩展 |
| ❌ 深度课程 | 路线图比课程更轻，更快出MVP |
| ❌ B端企业版 | 先验证C端付费意愿 |

### 3.2 US-01：一人公司方向诊断（P0）

**故事描述**：

```
作为想创业的普通人
我想知道最适合我的一人公司方向
这样我知道从哪开始
```

**验收标准**：

```
AC-01: 用户输入技能（如"写作/编程/设计/运营"）
AC-02: 用户输入兴趣（如"AI/出海/内容/工具"）
AC-03: 用户输入可用时间（兼职<10h / 全职>10h）
AC-04: 系统输出1-2个最适合的方向推荐
AC-05: 每个推荐包含：方向名称 + 匹配度评分 + 理由 + 风险提示
AC-06: 推荐方向来自8个已验证方向库（可扩展）
```

**技术要求**：

```
方向匹配：基于规则引擎（方向特征 vs 用户画像）
方向库：8个已验证方向的结构化描述
交互形式：微信对话框（最简单，用户最熟悉）
诊断模型：轻量级，用Claude/DeepSeek即可
```

## 四、商业模式

### 4.1 定价策略

| 产品 | 价格 | 说明 |
|------|------|------|
| 方向诊断 | 免费 | 引流，建立信任 |
| 工具包推荐 | 免费 | 引流，不收钱 |
| 7个月执行路线图 | ¥29/月 或 ¥199/年 | 核心产品 |
| 社群+答疑 | ¥99/月 | 高价值用户 |
| 一本通手册（PDF） | ¥49 一次性 | 低门槛尝鲜 |
| 工具包代购服务 | 佣金分成 | 被动收入 |

### 4.2 变现路径

```
第1个月：免费引流
→ 发公众号文章测试反响
→ 阅读量>5000 → 说明需求真实
→ 阅读量<2000 → 调整定位

第2个月：付费试点
→ 推出 ¥199/年 路线图订阅
→ 目标：第一个100个付费用户
→ 验证：愿意为什么付钱

第3个月：社群扩展
→ 推出 ¥99/月 社群
→ 目标：第一个50个社群用户
→ 案例：每人每年贡献 ¥996 = ¥50,000/年

第6个月：工具包代购
→ 对接工具Affiliate
→ 被动收入 = 佣金 × 用户数 × 转化率
```

### 4.3 成本估算

```
固定成本：
- AI API（Claude/DeepSeek诊断）: ¥100/月（1000次诊断）
- 微信模板消息: 免费
- 托管（Vercel/Railway）: ¥0-100/月

边际成本：
- 每个付费用户: ¥1-3/月（AI调用成本）
- 社群答疑: 时间成本

净利润：
- ¥199/年 × 100用户 = ¥19,900/年
- ¥99/月 × 50用户 × 12月 = ¥59,400/年
- 合计目标: ¥79,300/年 ≈ ¥6,600/月
```

## 六、技术架构

### 6.1 技术栈

```

- 微信对话框（最简单）

- Next.js API Routes

- 微信模板消息（每周任务提醒）
- 微信客服消息（答疑）

托管：
- Vercel

```
