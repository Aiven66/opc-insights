## 背景与痛点

**用户故事**：

小美，25岁，广州人，做TikTok Shop美妆品牌，每月GMV约$3万：
- 发100封邮件出去，回复不超过5个
- 每天花3小时刷TikTok找KOL，找了半天还不确定对不对
- 她说："我知道要找到合适的KOL，但根本不知道从哪下手找人啊"

**核心痛点**：

| # | 痛点 | 现状 |
|---|------|------|
| 1 | **找不到对的KOL** | 靠人工刷TikTok，效率低，判断靠直觉 |
| 2 | **找到KOL不知道怎么联系** | 不知道商务邮箱，很难找到 |
| 3 | **邮件像群发，回复率<5%** | 个性化太花时间 |
| 4 | **发完没有跟进** | 不知道谁看了、谁回复了 |
| 5 | **竞品太贵用不起** | Grin $3000/月，Aspire $1000/月 |

## 市场验证

**数据支撑**：

- TikTok Shop东南亚2024年GMV同比增长300%，KOL营销需求爆发
- 出海DTC品牌爆发，需要低成本KOL外联方案
- 邮件外联是出海ToB/ToC场景的标配渠道，回复率远高于社交DM
- 竞品太贵：Grin($3000/月)、Aspire($1000/月)

## 核心差异化：全链路AI驱动

### 传统方式 vs Kolify方式

```
传统方式（手工）：
  ❌ 人工刷TikTok → ❌ 一个个找邮箱 → ❌ 手工写邮件 → ❌ 复制粘贴发送 → ❌ 手动记录

Kolify方式（全链路AI）：
  ✅ 用自然语言描述目标 → ✅ AI自动找到匹配的KOL → ✅ AI生成个性化邮件 → ✅ AI自动发送 → ✅ AI追踪效果
```

## 核心功能详解

### F1: AI KOL发现（自然语言驱动）

**传统搜索**：
- 手动设置：粉丝量>10万 / 国家=美国 / 品类=美妆
- 结果：大量不相关的KOL，需要人工一个个筛选

**Kolify AI发现**：

```
用户输入（自然语言）：
"帮我找适合我们美妆品牌的TikTok KOL，
  粉丝在5-20万之间，
  主要做测评/试色内容，
  受众是18-25岁女性，
  在美国或英国，
  最近3个月有发布合作内容（说明她们愿意接合作）"

AI自动完成：
  Step 1：理解用户需求，拆解为搜索条件
  Step 2：在TikTok/IG/YouTube数据库中搜索
  Step 3：AI分析每个KOL的内容风格、受众画像、合作历史
  Step 4：输出匹配度评分Top 20的KOL列表

输出：
  🎯 匹配度95分：[@BeautyBySarah](TikTok) | 12万粉丝 | 美国 | 测评风格 | 愿意合作✅
  🎯 匹配度92分：[@GlowUpEmma](TikTok) | 8万粉丝 | 英国 | 试色+教程 | 愿意合作✅
  🎯 匹配度87分：[@LipstickLuna](Instagram) | 15万粉丝 | 美国 | 试色 | 未合作过⚠️
```

### F2: AI邮件生成

```
输入：
  - 品牌信息（产品名称、品牌调性、合作政策）
  - KOL数据（AI发现的）
  - 外联目标（合作/寄样/付费）

AI处理：
  Step 1：读取KOL最近20条内容
  Step 2：分析内容风格和合作偏好
  Step 3：根据品牌 + KOL → 生成个性化邮件

输出（3种风格）：
  📧 邮件A（热情型）："Hi Sarah，我看了你最近的[某视频]..."
  📧 邮件B（赞美型）："[具体夸赞]...正好我们在找..."
  📧 邮件C（价值型）："我们有个[产品]，很适合你的[受众]..."
```

### F4: AI自动发送

```
用户操作：
  1️⃣ 设置品牌资料（一次性）
  2️⃣ 用自然语言描述目标KOL
  3️⃣ 预览AI推荐的KOL列表（可修改）
  4️⃣ 预览AI生成的邮件（可选风格）
  5️⃣ 点击"AI自动发送"

AI自动完成：
  ✅ 连接用户的Gmail/SMTP邮箱
  ✅ 按设定时间间隔发送（防封号）
  ✅ 追踪邮件打开/点击/回复
  ✅ 对未回复者，自动提醒二次触达
  ✅ 记录所有数据到仪表盘

用户只需：等回复
```

## 技术方案

### 核心技术架构

```
用户输入（自然语言）
      ↓
自然语言理解（LLM）
      ↓
KOL数据库查询（TikTok/IG/YouTube API）
      ↓
AI内容分析 + 匹配度评分
      ↓
AI邮件生成（Claude API）
      ↓
邮件发送（Gmail API / SendGrid）
      ↓
效果追踪（打开率/点击率/回复率）
```

### 核心数据源

| 平台 | API/方式 | 用途 |
|------|----------|------|
| TikTok | Creator Marketplace API | KOL发现：基础信息/粉丝量/互动率 |
| Instagram | Graph API + RapidAPI | KOL发现：帖子/互动数据 |
| YouTube | YouTube Data API | KOL发现：订阅者/观看量 |
| Apollo.io | KOL数据库 + 邮箱挖掘 | 综合KOL发现 + 商务邮箱 |
| Hunter.io | 邮箱挖掘API | 找KOL的商务邮箱 |

### 技术栈

```
前端: Next.js + TailwindCSS + shadcn/ui
后端: Next.js API Routes
数据库: Supabase (PostgreSQL)
AI发现: Claude API (自然语言理解 + KOL分析)
AI邮件生成: Claude API
邮件发送: Gmail API / SendGrid
KOL数据: TikTok Creator Marketplace + Apollo.io + RapidAPI
部署: Vercel + Supabase
```
