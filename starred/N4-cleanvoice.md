## 真实痛点

```
用户场景：
- 播客录制环境嘈杂（咖啡厅/家里/户外）
- 录音有风扇声/空调声/键盘声
- 视频创作者需要干净音轨
- 会议录音有回声

现有解决方案的问题：
- Adobe Audition：太专业，学习成本高
- Adobe Podcast：免费但需注册
- Veed.io：$12/月，功能太多
- Audacity：免费但需手动处理

用户需求：
→ 一键去除背景噪音
→ 不需要任何音频处理经验
→ 5分钟内出结果
→ 免费先试，付费再买
```

## MVP设计

### 核心功能

```
1. 音频上传
   支持：MP3 / WAV / M4A / OGG
   最大：100MB / 60分钟

2. AI去噪
   自动检测并去除：
   - 背景噪音（风扇/空调/交通）
   - 回声
   - 呼吸声
   - 电流声

3. 预览 + 下载
   - 预览处理前后对比
   - 一键下载干净音频
```

### 附加功能（v2）

```
- 去除人声（提取背景音乐）
- 音量标准化
- 音频压缩
```

  选项C：自建Whisper+降噪模型
部署：Vercel
支付：Stripe
域名：cleanvoice.ai / cleanaudio.ai
