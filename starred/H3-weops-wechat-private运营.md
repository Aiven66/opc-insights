## 一、产品概述

### 1.1 一句话定位

帮私域创业者用AI自动化社群运营、朋友圈文案、用户跟进，降低运营成本。

### 1.2 Slogan

**"让AI替你运营私域，省时间，多赚钱"**

### 1.3 解决的问题

```
用户痛点：
❌ 社群运营每天花2-3小时回复重复问题
❌ 不知道发什么朋友圈，内容焦虑
❌ 用户标签靠记忆，容易遗漏
❌ 想跟进用户但不知道什么时候发消息

WeOps的方案：
✅ AI群回复助手：自动生成回复，一键发送
✅ 朋友圈AI：自动生成朋友圈文案
✅ 私域CRM：AI记录用户标签 + 生成跟进话术
✅ 定时发送：提前准备好，定时发布
```

### 1.4 目标用户

```
🎯 私域创业者：微信里有1000+用户，想自动化运营
🎯 社群群主：运营多个微信群，每天花大量时间回复
🎯 内容博主：有公众号，想复用内容做朋友圈/社群
🎯 微商/电商：私域用户管理+AI话术生成
```

### 1.5 市场机会

```
市场背景：
- 中国私域用户超10亿
- 微信月活超13亿
- 私域运营市场规模超1000亿元/年
- 大量SaaS工具在做私域管理（微盛/企微/有赞等）

AI化机会：
- 现有工具以"管理"为主，AI化程度低
- AI生成回复/文案 = 差异化竞争点
- 用户愿意为"省时间"付费
```

## 二、核心功能矩阵

### 2.1 MVP核心功能

```
【WeOps - 微信私域AI运营助手】

核心功能（2周MVP）：
1. AI群回复助手
   → 用户设置关键词和回复规则
   → AI根据上下文生成回复
   → 用户一键发送或修改后发送

2. 朋友圈AI
   → 输入产品/话题 → AI生成朋友圈文案
   → 提供3种风格（卖货/种草/生活）
   → 一键复制或定时发布

3. 基础私域CRM
   → 用户标签记录
   → 跟进提醒
   → 跟进话术生成

免费版：每天10次AI回复
Pro版：¥99/月，无限次 + 朋友圈AI + CRM
Business版：¥299/月，+ 批量管理 + 数据分析
```

## 七、合规说明

### 7.1 微信API合规

```
⚠️ 重要风险：

微信个人号：
- 使用网页协议存在封号风险
- 不建议大规模使用
- 建议优先企业微信API

企业微信：
- 官方提供API，合规
- 需要企业认证
- 更稳定，但用户门槛更高

建议：
- MVP阶段：先做企业微信版本
- 风险更低，合规性更好
```

### 7.2 功能合规

```
WeOps的定位：
= 辅助工具（帮用户生成内容）
≠ 自动化工具（代替用户操作）

功能边界：
✅ AI生成回复内容（用户自己发送）
✅ AI生成朋友圈文案（用户自己发布）
✅ 提醒用户跟进（用户自己跟进）

❌ 不能做：
❌ 自动发送消息（违反微信规定）
❌ 模拟用户操作（封号风险）
```

→ 解决：持续关注微信政策
→ 只做内容生成，不做自动发送
