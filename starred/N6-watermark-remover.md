## 真实痛点

```
用户场景：
- 下载的图片有水印，想用于PPT/文档
- 产品图有版权水印，想做参考
- 旧照片有日期水印
- 网上素材有平台水印

现有解决方案的问题：
- Photoshop：需要手动修补，太专业
- Inpaint：需注册，界面复杂
- 在线工具：大多数收费或有水印
- 手动PS：费时间，效果差

用户需求：
→ 上传图片
→ 用画笔涂抹水印区域
→ AI自动去除并填充
→ 下载干净图片
```

## MVP设计

### 核心功能

```
1. 图片上传
   支持：JPG / PNG / WEBP
   最大：10MB / 4096×4096px

2. 水印涂抹
   - 画笔工具涂抹水印区域
   - 画笔大小可调
   - 可撤销/重做

3. AI去除
   - 点击"去除"按钮
   - AI分析周围区域
   - 智能填充水印位置

4. 预览 + 下载
   - 前后对比滑块
   - 一键下载PNG
```
