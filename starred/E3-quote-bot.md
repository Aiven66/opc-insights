## 一句话定位

> 客户发来PDF询价表，AI自动识别规格，匹配产品库，一键生成专业报价单。

---

## 背景与痛点

**用户故事**：

David，广州某工业零部件出口商，做B2B外贸5年：
- 每个月收到几十封邮件，带着PDF/Excel询价表
- 询价表里有几十种规格型号，要一个个在系统里查价格
- 一个报价来回2-3天，客户不耐烦，转向能快速响应的供应商
- 报价单格式不专业，被客户质疑

**核心痛点**：
1. PDF/Excel询价表解析靠人肉，效率低，容易出错
2. 产品规格复杂（型号/数量/材质/工艺），匹配产品库困难
3. 报价周期长（2-3天），客户流失
4. 报价单格式不专业，影响品牌形象

---

## 市场验证

**数据支撑**：
- 出海B2B持续火热，工业/电子/化工类询价需求大
- 中国B2B出口规模持续增长，数字化转型加速
- 竞品缺失：主流ERP（SAP/Oracle）太贵太重，不适合中小B2B

| 竞品 | 定价 | 痛点 |
|------|------|------|
| SAP Business One | ¥10万+/年 | 太贵，中小企业用不起 |
| Zoho CRM | $12/月/人 | 不够专业，无报价单生成 |
| 自研Excel | 0 | 效率低，不可复用 |
| **QuoteBot（机会）** | $29-299/月 | 专为B2B外贸设计，AI驱动 |

## 技术方案

### 核心技术

| 技术 | 用途 |
|------|------|
| Claude Document AI | PDF/图片询价表解析 |
| Supabase | 产品库数据库 |
| Puppeteer/Playwright | PDF报价单生成（渲染HTML→PDF） |
| DeepL/Google Translate | 多语言翻译 |

### AI功能

```
PDF上传 → Claude解析（识别表格/规格/数量）
         → 智能匹配产品库（模糊匹配/型号相似度）
         → 生成报价草稿（产品/数量/单价/总价/交期）
         → 用户确认 → 生成PDF报价单
```

### 技术栈建议

```
前端: Next.js + TailwindCSS + shadcn/ui
后端: Next.js API Routes
数据库: Supabase (PostgreSQL)
AI: Claude API (PDF解析 + 产品匹配)
PDF: Puppeteer / React-PDF
部署: Vercel
```
