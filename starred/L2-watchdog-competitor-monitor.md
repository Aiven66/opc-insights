## 一句话定位

> 帮出海独立开发者，盯着竞品的一举一动。

---

## 背景与痛点

**用户故事**：

小张，出海SaaS创始人，做了一款AI写作工具：
- 竞品A刚降价了，不知道为什么
- 竞品B上周上新了一个功能，自己的用户可能也在用
- 竞品C的官网改版了，文案变了，不知道在主打什么
- 这些信息都是自己手动盯着，效率低，容易漏

**核心痛点**：
1. 不知道竞品什么时候变了（价格/功能/文案/页面）
2. 手动盯着太累，靠人工根本盯不过来
3. 变化发生后才知道，太被动
4. 没有系统化的竞品数据，复盘全靠感觉

---

## 市场验证

**数据支撑**：
- 出海DTC品牌爆发，独立开发者出海增多
- ProductHunt每日新产品，需要持续监控
- 竞品分析是产品经理核心技能，但独立开发者没时间做

**竞品分析**：

| 竞品 | 定价 | 痛点 |
|------|------|------|
| SEMrush | $120/月+ | 太贵，面向大企业 |
| Ahrefs | $99/月+ | 太贵，偏SEO |
| SimilarWeb | $199/月+ | 太贵，数据不够细 |
| **WatchDog（机会）** | $19-49/月 | 专为独立开发者设计 |

## MVP功能清单

### P0（核心闭环）

| # | 功能 | 描述 |
|---|------|------|
| F1 | **竞品添加** | 输入竞品URL/App名称，自动抓取基本信息 |
| F2 | **变化监控** | 监控竞品官网/App Store/社交媒体变化 |
| F3 | **变化告警** | 竞品变化时，微信/邮件推送告警 |
| F4 | **竞品周报** | 每周自动生成竞品动态简报 |

### P1（运营闭环）

| # | 功能 | 描述 |
|---|------|------|
| F5 | **变化历史** | 查看竞品过去30天/90天的所有变化 |
| F6 | **对比视图** | 品牌A vs 品牌B，变化趋势对比 |
| F7 | **截图存档** | 每次变化自动截图存档 |
| F8 | **标签分类** | 按产品线/功能/价格分类竞品 |

### P2（增长功能）

| # | 功能 | 描述 |
|---|------|------|
| F9 | **App Store监控** | 监控iOS/Android App变化 |
| F10 | **社交媒体监控** | Twitter/LinkedIn/ProductHunt帖子 |
| F11 | **价格历史** | 竞品价格变化曲线图 |
| F12 | **用户告警群** | 变化推送到飞书群/Discord |

## 技术方案

### 数据源

| 平台 | 方式 | 数据 |
|------|------|------|
| 竞品官网 | 网页抓取 | 页面内容/价格/文案 |
| App Store | API/抓取 | 版本更新/评分/描述 |
| ProductHunt | API | 新产品发布 |
| Twitter | API | 官方动态 |

### 技术栈

```
前端: Next.js + TailwindCSS
后端: Next.js API + Cron Jobs
数据库: Supabase
告警: 微信模板消息 / SendGrid
抓取: Puppeteer / Firecrawl
部署: Vercel
```
