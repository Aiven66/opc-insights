## 一句话定位

> 帮出海品牌，用AI监控Twitter/Reddit/HN上的口碑，异常波动实时告警。

---

## 背景与痛点

**用户故事**：

Lisa，深圳某DTC美妆品牌创始人，团队5个人：
- 在亚马逊/TikTok Shop卖美妆，想知道欧美用户怎么评价自己的品牌
- 竞品出了新品，想第一时间知道网上讨论什么
- 没有预算买Meltwater（$800/月），也没有专人做舆情监控
- 只能靠人工刷Twitter/Reddit，效率低，容易漏

**核心痛点**：
1. 出海品牌需要知道自己在社交媒体的"声音"，但Meltwater太贵
2. 竞品动态、市场口碑，全靠人工搜集
3. 出现负面评论时，往往已经发酵几天了
4. 没有系统化的舆情数据，复盘全靠"感觉"

---

## 市场验证

**数据支撑**：
- TrendRadar GitHub 54k⭐，赛道被验证
- 出海DTC品牌爆发，品牌监控需求激增
- TikTok Shop东南亚2024年GMV同比增长300%
- 竞品太贵：Meltwater($800/月)、Brandwatch($300/月)，中小品牌用不起

**竞品分析**：

| 竞品 | 定价 | 痛点 |

## MVP功能清单

### P0（核心闭环）

| # | 功能 | 描述 |
|---|------|------|
| F1 | **品牌关键词监控** | 输入品牌名+竞品名，自动追踪Twitter/X/Reddit/HN讨论 |
| F2 | **情感分析** | AI自动判断每条讨论是正向/负面/中性 |
| F3 | **异常波动告警** | 当负面讨论突然增加时，微信/邮件推送告警 |
| F4 | **每日舆情日报** | 每天早上自动生成舆情简报，推送到微信/邮件 |

### P1（运营闭环）

| # | 功能 | 描述 |
|---|------|------|
| F5 | **竞品对比** | 品牌A vs 品牌B，声量/情感对比图 |
| F6 | **热门话题发现** | 自动发现近期最热门的相关话题 |
| F7 | **历史数据查询** | 查询过去30天/90天的舆情趋势 |
| F8 | **多平台支持** | Twitter/X、Reddit、HackerNews、Instagram |

### P2（增长功能）

| # | 功能 | 描述 |
|---|------|------|
| F9 | **KOL提及追踪** | 追踪哪些KOL提到了品牌/竞品 |
| F10 | **小红书/微博监控** | 覆盖国内社交平台（可选插件） |
| F11 | **周报/月报生成** | 更详细的周期性报告，支持导出PDF |
| F12 | **API集成** | 开放API，支持与企业系统对接 |

## 技术方案

### 数据源集成

| 平台 | API/方式 | 数据 |
|------|----------|------|
| Twitter/X | Academic API / 部分免费 | 推文、转发、回复 |
| Reddit | Reddit API（免费） | 帖子、评论 |
| HackerNews | Firebase API（免费） | 帖子、投票 |
| Instagram | Instagram Graph API | 帖子、评论 |

### AI功能

```
原始数据 → 去重/清洗
         → Claude情感分析（正向/负面/中性 + 原因）
         → 异常检测（负面突然增加？）
         → 生成每日简报（3句话总结 + 关键事件）
```

### 技术栈建议

```
前端: Next.js + TailwindCSS + shadcn/ui
后端: Next.js API Routes + Cron Jobs
数据库: Supabase (PostgreSQL)
AI: Claude API (情感分析 + 日报生成)
数据: Reddit/HN API免费，Twitter需申请
告警: 微信模板消息 / SendGrid邮件
部署: Vercel
```
