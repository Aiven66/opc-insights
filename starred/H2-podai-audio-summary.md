## 一、产品概述

### 1.1 一句话定位

帮播客听众和内容创作者快速获取音频/视频的核心内容，节省时间。

### 1.2 Slogan

**"Turn hours of audio into minutes of insights"**

### 1.3 解决的问题

```
用户痛点：
❌ 想听播客，但没时间（1-2小时的节目太多）
❌ 看完视频/听完音频，发现内容很水
❌ 收藏了很多内容，但从来不会再看
❌ 想分享播客亮点给别人，但总结太麻烦

PodAI的方案：
✅ Whisper转录：把音频/视频转成文字
✅ AI摘要：生成3-5个核心要点
✅ 时间戳导航：点击跳转到对应段落
✅ 多语言支持：英文/中文/日文等
```

### 1.4 目标用户

```
🎯 播客听众：想快速了解播客内容，但不花2小时听
🎯 内容创作者：需要参考资料，但不看完整个视频
🎯 学生/研究人员：需要快速获取访谈/演讲内容
🎯 Newsletter作者：需要引用播客内容
```

### 1.5 市场机会

```
市场背景：
- 全球播客听众超5亿
- 每月新增播客节目超10万个
- "podcast transcription" 月搜索量：~5万次/月
- "AI podcast summary" 月搜索量：快速增长

付费意愿：
- Otter.ai：$20/月（转录+摘要）
- Descript：$24/月（转录+编辑）
- 市场需求：用户愿意为"省时间"付费
```

## 二、核心功能矩阵

### 2.1 MVP核心功能

```
【PodAI - AI播客摘要生成器】

核心功能（1周MVP）：
1. 输入：播客/视频URL（YouTube/Podcast/Spotify）
2. Whisper转录：自动转成文字
3. AI摘要：生成3-5个核心要点 + 关键引用
4. 时间戳导航：点击跳转到对应段落

免费版：每月5次，每次30分钟以内
Pro版：$12/月，无限次 + 更长音频 + 多语言
Business版：$39/月，团队协作 + API
```

### 2.2 功能规划（v1.1-v2.0）

| 版本 | 功能 | 说明 |
|------|------|------|
| v1.0 MVP | URL → 转录+摘要 | 核心闭环 |
| v1.1 | 上传音频文件 | 支持本地文件 |
| v1.2 | Newsletter导出 | 导出为可分享的摘要 |
| v2.0 | 播客RSS订阅 | 批量处理喜欢的播客 |

## 五、竞品分析

### 5.1 竞品对比

| 竞品 | 定价 | AI摘要 | 缺点 |
|------|------|--------|------|
| Otter.ai | $20/月 | ⚠️ 基础 | 无AI摘要，偏向会议 |
| Descript | $24/月 | ✅ 有 | 偏向编辑，功能复杂 |
| Snipd | $9.99/月 | ✅ 有 | 只支持部分播客 |
| **PodAI** | $12/月 | ✅ 有 | 从零开始 |

### 5.2 PodAI的差异化

```
差异化1：极简体验
→ 输入URL → 自动转录+摘要 → 阅读3分钟核心内容
→ 3步完成，不需要学任何东西

差异化2：多平台支持
→ 支持YouTube/Podcast/Spotify/本地文件
→ 竞品要么只支持播客，要么只支持YouTube

差异化3：面向海外
→ 英文界面，美元定价
→ 全球播客用户都是目标用户
```
