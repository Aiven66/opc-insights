## 🟡 信号五： Coding Agent的关键是"开头规划"

**原始数据**（来自@宝玉的观察）：
```
用好 Coding Agent，重点是两头。
尤其是开头的部分。
如果一开始就走偏了，后面怎么改都改不好。
```

**这是一个被忽视的洞察**：

```
现在的AI圈都在讨论：
- 模型能力够不够强
- Agent能不能多步推理
- 上下文够不够长

但没人讨论：
- 用户能不能描述清楚自己的需求？
- "开头规划"这个环节有没有工具？
```

**这是一个完全空白的需求**：

```
用户问题：
"我不知道怎么跟AI说我要什么"

现有解决方案：
- 提示词工程（教用户写好提示）
- AI助手（让AI帮你生成提示）

缺失的解决方案：
- "需求清晰度评估"工具
- "AI任务规划"工具
```

**类比**：互联网时代，大家都在优化"搜索引擎"，但没人在乎"搜索词的准确性"。后来百度/Google都做了"搜索建议"功能来解决这个问题。

**对Aiven的直接意义**：ArticleShort的核心功能之一就是"把你的文章变成好的视频脚本"——本质上就是"需求/内容清晰度评估"。用户写了文章，但不知道这个文章适不适合做视频、怎么改才能做视频。ArticleShort帮你评估+改造。
