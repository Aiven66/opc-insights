## 技能概述

| 功能 | 触发词 | 输出 |
|------|--------|------|
| **每日洞察日报** | 洞察日报 / MVP日报 / 今日洞察 / OPC简报 | 每天6个MVP方向 |

## 功能一：每日洞察日报

### 触发词

```
洞察日报 / MVP日报 / 今日洞察 / OPC简报 / 产品方向 / 机会
```

### 运行命令

```bash
cd ~/opc-insights && python3 scripts/generate_v10.py
```

### 输出

```
reports/mvp-insights-yc-YYYY-MM-DD.md
```

---

## 功能二：产品11问深度评估

### 触发词

```
产品11问 / 产品评估 / 11 questions / 验证产品方向 / 评估这个产品 / 产品可行性分析 / 分析PostAI / 深度评估方向
```

### 运行方式

**方式1：命令行**

```bash
cd ~/opc-insights && python3 scripts/product_11_questions.py "产品名称" "一句话定位"
```

**方式2：交互式**

```bash
cd ~/opc-insights && python3 scripts/product_11_questions.py
# 按提示输入产品信息
```

**方式3：分析已有星标产品**

```bash
cd ~/opc-insights && python3 scripts/product_11_questions.py --starred "H3-PostAI"
```

### 输出

```
starred/*-11问-YYYY-MM-DD.md
```

## 11问评估模板

### Q1-Q11 完整框架

| # | 问题 | 核心目的 | 输出 |
|---|------|---------|------|
| 1 | 产品要解决什么问题？ | 痛点真实性 | 1句话 + 用户视角 + 马斯洛层次 |
| 2 | 为谁解决这些问题？ | 目标用户 | 用户画像（7个维度） |
| 3 | 有多少人真的需要？ | 市场规模 | TAM/SAM/SOM + 数据信号 |
| 4 | 目前有哪些解决方案？ | 竞品分析 | 直接竞品 + 隐藏竞品 + 优劣势 |
| 5 | 我们的解决方案是什么？ | 差异化定位 | MVP功能 + 优势矩阵 |
| 6 | 怎么判断产品第一阶段成功？ | 成功指标 | 北极星指标 + 辅助指标 |
| 7 | 现在做的时机合适吗？ | 时机判断 | 信号分析 + 注意点 |
| 8 | 成功的必要条件是哪些？ | 关键路径 | 必要条件 + 非必要条件 |
| 9 | 这个产品有哪些重要原则？ | 价值观对齐 | 3-5个核心原则 |
| 10 | 怎样完成冷启动？ | 增长飞轮 | 分阶段策略 + 渠道 |
| 11 | 优先验证哪些价值点？ | 验证优先级 | 验证点排序 + 验证方法 |

## 使用示例

### 示例1：评估PostAI

```
用户：帮我用产品11问评估PostAI（AI社媒文案生成器）

Agent：
1. 读取产品信息（H3-PostAI.md）
2. 运行产品11问分析
3. 输出完整评估报告到 starred/H3-PostAI-11问-2026-05-31.md
```

### 示例2：评估CleanVoice

```
用户：产品11问分析 CleanVoice 音频去背景音

Agent：
1. 读取产品信息（N4-cleanvoice.md）
2. 按11问模板逐一分析
3. 输出综合评分和行动建议
```

### 示例3：命令行直接分析

```bash
# 方式1：完整问答
python3 scripts/product_11_questions.py

# 方式2：指定产品
python3 scripts/product_11_questions.py "UpscaleAI" "AI图片无损放大工具"

# 方式3：分析已有星标产品
python3 scripts/product_11_questions.py --starred "N5-upscaleai"
```
